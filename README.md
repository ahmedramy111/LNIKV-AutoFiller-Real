# LYNIKV AutoFiller Real V4

للاستخدام على منصتك وحسابات الاختبار المملوكة لك.

## 1) إعداد الرابط
افتح `config.js` وضع رابط منصتك في `PLATFORM_URL`.

## 2) تثبيت وتشغيل
```bash
npm install
npx playwright install chromium
npm start
```

## 3) السرعة
`FAST_DELAY_MS=0` افتراضيًا. لوحة التحكم الخاصة تسمح بتفعيل التسريع أثناء الجلسة.

## 4) التقاط الإجابات قبل التدريب
العامل يأخذ snapshot لمحتوى الدرس قبل الضغط على بدء التدريب، ويحاول استخراج نصوص النسخ والكود الظاهر، ثم يستخدمها أثناء التدريب. إذا لم يجد إجابة بثقة، يتوقف بدل التخمين.

## 5) محددات المنصة
إذا كانت عناصر المنصة لا تطابق المحددات العامة، ضع CSS selectors في `config.js`. لا تحتاج لتعديل كود منصتك.

## 6) لوحة المدير
المسار الخاص يأتي من `ADMIN_PATH`. المسار وحده ليس حماية؛ استخدم كلمة مرور قوية ومتغيرات بيئة:
`ADMIN_USER`, `ADMIN_PASS`, `ADMIN_PATH`.

لا تضع كلمات المرور الحقيقية في GitHub.
